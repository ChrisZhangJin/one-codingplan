GREEN phase -- implement internal/pool/probe.go:

Package `pool`.

Per-provider probe model map:
```go
var probeModels = map[string]string{
    "kimi":    "moonshot-v1-8k",
    "qwen":    "qwen-turbo",
    "glm":     "glm-4-flash",
    "minimax": "MiniMax-Text-01",
}

func probeModel(provider string) string {
    if m, ok := probeModels[provider]; ok {
        return m
    }
    return "gpt-3.5-turbo"
}
```

`runProbeLoop()`:
1. `ticker := time.NewTicker(time.Hour)`
2. `defer ticker.Stop()`
3. Select on `ticker.C` and `p.stopCh`

`probeAll()`:
1. Take RLock, collect entries where `!available` into a local slice, release RLock
2. For each collected entry, call `sendProbe(e)`. If true, call `p.Mark(e.ID, true)`

`sendProbe(e entry) bool`:
1. Build JSON body: `{"model":"<model>","messages":[{"role":"user","content":"hi"}],"max_tokens":1}` using `probeModel(e.Name)`
2. Create request with `context.WithTimeout(context.Background(), 10*time.Second)`
3. POST to `e.BaseURL + "/v1/chat/completions"`
4. Set headers: `Content-Type: application/json`, `Authorization: Bearer ` + e.APIKey
5. Read response body with `io.LimitReader(resp.Body, 64*1024)` per T-02-01
6. Check: `resp.StatusCode >= 200 && resp.StatusCode < 300` AND `Classify(e.Name, resp.StatusCode, respBody) != ClassCreditsExhausted`
7. Return true only if both conditions pass

Use `http.Client{Timeout: 10 * time.Second}` as a package-level var (not DefaultClient).
