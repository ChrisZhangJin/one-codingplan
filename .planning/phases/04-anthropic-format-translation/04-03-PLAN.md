**Create `internal/server/anthropic.go`** with three functions:

**1. `handleAnthropicRelay(c *gin.Context)`** — mirrors `handleRelay` structure:
- Read body with 10MB limit (same as handleRelay, T-3-03 pattern).
- Parse body as `translator.AnthropicRequest` via `json.Unmarshal`. Return 400 on parse failure with `{"type":"error","error":{"type":"invalid_request_error","message":"..."}}` (Anthropic error format).
- Save `originalModel := req.Model` for response echo (D-03).
- Get `keyID` from context (set by authMiddleware).
- Failover loop (identical structure to handleRelay):
  - `s.pool.Select(keyID)` → get upstream
  - `seen[up.ID]` check → break if already tried
  - Call `translator.AnthropicToOpenAI(&req, current.ModelOverride)` to produce OpenAI request body (D-01/D-02)
  - Marshal translated request to JSON bytes
  - Create `http.NewRequestWithContext` to `current.BaseURL + "/v1/chat/completions"` with translated body
  - Set headers: `cloneHeaders(c.Request.Header)`, replace `Authorization` with upstream key, delete `Host`
  - Replace `Content-Type` header with `application/json` (incoming may have Anthropic-specific headers)
  - `relayClient.Do(outReq)`
  - On error: continue (rotate)
  - On 4xx/5xx: read error body, `pool.Classify`, handle credits/rate-limit/transient (same as handleRelay)
  - On success: branch on `req.Stream`:
    - `true` → `proxyAnthropicStream(c, resp, cancel, keyID, current.ID, start, originalModel)`
    - `false` → `proxyAnthropicBuffer(c, resp, cancel, keyID, current.ID, start, originalModel)`
  - Return after success path
- After loop: return 503 with Anthropic error format: `{"type":"error","error":{"type":"overloaded_error","message":"no upstream available"}}`
- Log usage on 503 path.

**2. `proxyAnthropicBuffer(c, resp, cancel, keyID, upstreamID, start, originalModel)`**:
- `defer cancel()`, read upstream body, close resp.Body.
- Parse upstream body as `translator.OpenAIResponse`.
- Call `translator.OpenAIToAnthropic(&oaiResp, originalModel)` to translate.
- Set `Content-Type: application/json`.
- Marshal and write the `AnthropicResponse` with status 200.
- Log usage with token counts from the translated response.

**3. `proxyAnthropicStream(c, resp, cancel, keyID, upstreamID, start, originalModel)`**:
- `defer cancel()`, `defer resp.Body.Close()`.
- Set streaming headers: `Content-Type: text/event-stream`, `X-Accel-Buffering: no`, `Cache-Control: no-cache`, `Connection: keep-alive`. WriteHeader 200.
- Get `http.Flusher`.
- Create `sync.Mutex` + `writeAndFlush` helper (same pattern as proxyStream in relay.go).
- Start heartbeat goroutine (same pattern as proxyStream).
- Create `st := translator.NewStreamTranslator(originalModel)`.
- Read loop: `resp.Body.Read(buf)` → `st.Translate(buf[:n])` → for each emitted event, `writeAndFlush(event)`.
- After loop ends (EOF or error): log usage (streaming tokens = 0 per existing convention).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /v1/messages handler | Untrusted Anthropic JSON body |
| handler -> upstream | Translated request with upstream API key |
| upstream -> handler -> client | Upstream response translated and returned |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-07 | Tampering | handleAnthropicRelay body parse | mitigate | json.Unmarshal into typed AnthropicRequest struct; malformed JSON returns 400 with Anthropic error format |
| T-4-08 | DoS | handleAnthropicRelay body size | mitigate | 10MB body limit via io.LimitReader (same as handleRelay, T-3-03 pattern) |
| T-4-09 | Spoofing | /v1/messages auth bypass | mitigate | Route registered under v1 group which has authMiddleware; 401 for invalid/missing tokens |
| T-4-10 | Information Disclosure | Upstream API key in response | mitigate | cloneHeaders strips hop-by-hop; Authorization header replaced (not forwarded); upstream error bodies may leak provider info — accepted (admin-only access) |
| T-4-11 | Tampering | proxyAnthropicStream concurrent writes | mitigate | sync.Mutex guards all c.Writer writes (heartbeat + main loop) — same pattern as proxyStream |
</threat_model>
