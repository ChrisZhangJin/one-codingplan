```go
    Model     string          `json:"model,omitempty"`
```

**Step 2: Create `internal/translator/request.go`** with:

```go
func AnthropicToOpenAI(req *AnthropicRequest, modelOverride string) (*OpenAIRequest, error)
```

Implementation logic:
- If `modelOverride != ""`, set `out.Model = modelOverride` (D-01). Otherwise leave `out.Model = ""` which omits it from JSON due to `omitempty` (D-02).
- If `req.MaxTokens == 0`, set `out.MaxTokens = 4096` (safe default per Research pitfall 2).
- If `req.System != ""`, prepend `OpenAIMessage{Role: "system", Content: req.System}` to messages.
- For each `AnthropicMessage`, handle `Content` field which is `interface{}`:
  - If it's a `string`: create `OpenAIMessage{Role: m.Role, Content: contentStr}`
  - If it's a `[]interface{}` (JSON array): iterate blocks. Parse each as `AnthropicContentBlock`:
    - `type:"text"` blocks: concatenate `.Text` into a single content string for the OpenAI message
    - `type:"tool_use"` blocks (in assistant messages): create `OpenAIToolCall{ID: block.ID, Type: "function", Function: {Name: block.Name, Arguments: string(block.Input)}}` and add to the assistant message's `ToolCalls`
    - `type:"tool_result"` blocks (in user messages): create a separate `OpenAIMessage{Role: "tool", ToolCallID: block.ToolUseID, Content: extractToolResultContent(block)}`
- For `req.Tools`: translate each `AnthropicTool` to `OpenAITool{Type: "function", Function: {Name: t.Name, Description: t.Description, Parameters: t.InputSchema}}`
- Set `out.Stream = req.Stream`, `out.MaxTokens = req.MaxTokens` (or 4096 default)

Helper function `extractToolResultContent` handles `tool_result.content` which can be a string or array of text blocks — extract text content as a string.

Add a method `SetModelOverride(id uint, override string)` to Pool, or have main.go set it after pool construction by matching config upstream names. The simplest approach: after `pool.New()`, iterate `cfg.Upstreams` and call a new `Pool.SetModelOverride(name, override)` method that finds the entry by name and sets the field.

Add to Pool:
```go
func (p *Pool) SetModelOverride(name, override string) {
    p.mu.Lock()
    defer p.mu.Unlock()
    for i := range p.entries {
        if p.entries[i].Name == name {
            p.entries[i].ModelOverride = override
            return
        }
    }
}
```
