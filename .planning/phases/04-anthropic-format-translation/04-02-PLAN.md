Create `internal/translator/stream.go` with:

```go
type StreamTranslator struct {
    model   string
    started bool
    buf     []byte
}

func NewStreamTranslator(originalModel string) *StreamTranslator

// Translate accepts raw upstream bytes, returns 0+ complete Anthropic SSE event byte slices.
func (st *StreamTranslator) Translate(chunk []byte) ([][]byte, error)
```

Implementation:
1. Append `chunk` to `st.buf`.
2. Scan `st.buf` for complete SSE frames (delimited by `\n\n`). For each complete frame:
   a. Strip `data: ` prefix from the line.
   b. If data is `[DONE]`: emit closing sequence (content_block_stop, message_delta with stop_reason "end_turn", message_stop). Set started=false or mark done.
   c. Parse as JSON OpenAI streaming chunk: `{"choices":[{"delta":{"content":"..."},"finish_reason":null}]}`
   d. Extract `choices[0].delta.content` and `choices[0].finish_reason`.
   e. If content is empty and finish_reason is null/empty: skip (emit nothing).
   f. If `!st.started` and content is non-empty:
      - Emit `message_start` event with `{type:"message_start",message:{id:"msg_proxy",type:"message",role:"assistant",content:[],model:st.model,stop_reason:null,stop_sequence:null,usage:{input_tokens:0,output_tokens:0}}}`
      - Emit `content_block_start` event with `{type:"content_block_start",index:0,content_block:{type:"text",text:""}}`
      - Set `st.started = true`
   g. If content is non-empty: emit `content_block_delta` with `{type:"content_block_delta",index:0,delta:{type:"text_delta",text:"<content>"}}`
   h. If `finish_reason` is non-empty (and not null): emit closing sequence with translated stop_reason.
3. Leave any remaining partial bytes in `st.buf` for next call.

SSE event format function:
```go
func formatSSEEvent(eventType string, payload interface{}) ([]byte, error)
```
Produces: `event: <eventType>\ndata: <json>\n\n`

Use lightweight inline structs for event payloads rather than defining named types for each event — they are write-only serialization structs.
