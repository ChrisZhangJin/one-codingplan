<objective>
Build the relay pipeline core: auth middleware that validates bearer tokens against the access_keys table, a relay handler that forwards OpenAI-format chat completion requests to the selected upstream with failover across the pool, and async usage logging to SQLite.

Purpose: This is the central value of ocp -- a request enters, gets authenticated, is forwarded to an upstream, and if that upstream fails, the next one is tried transparently. Non-streaming path first; streaming added in Plan 02.

</objective>

    Failover loop (implements D-04, D-05):
    ```
    seen := make(map[uint]bool) // track unique upstreams tried
    var current *pool.UpstreamEntry
    for {
        if rateLimitRetry && current != nil {
            // retry same upstream after backoff (D-05 rate-limit)
            rateLimitRetry = false
        } else {
            // get next upstream from pool
            up, err := s.pool.Select(keyID)
            if errors.Is(err, pool.ErrNoUpstreams) {
                // no upstreams at all -> 503
                break
            }
            if seen[up.ID] {
                // already tried this one -> exhausted pool (D-04)
                break
            }
            seen[up.ID] = true
            current = up
        }
        lastUpstream = current

        // build outbound request
        ctx, cancel := context.WithTimeout(c.Request.Context(), 30*time.Second)
        outReq, _ := http.NewRequestWithContext(ctx, http.MethodPost,
            current.BaseURL+"/v1/chat/completions",
            bytes.NewReader(bodyBytes))
        outReq.Header = cloneHeaders(c.Request.Header)
        outReq.Header.Set("Authorization", "Bearer "+current.APIKey)
        outReq.Header.Del("Host")

        resp, err := relayClient.Do(outReq)
        cancel()
        if err != nil {
            // timeout or network error -> transient, rotate
            continue
        }

        if resp.StatusCode >= 400 {
            respBody, _ := io.ReadAll(io.LimitReader(resp.Body, 64*1024))
            resp.Body.Close()
            class := pool.Classify(current.Name, resp.StatusCode, respBody)
            switch class {
            case pool.ClassCreditsExhausted:
                s.pool.Mark(current.ID, false) // D-05
                continue // rotate to next
            case pool.ClassRateLimited:
                time.Sleep(s.pool.Backoff()) // D-05
                rateLimitRetry = true
                continue // retry same upstream
            default: // transient
                continue // rotate to next
            }
        }

        // Success path (non-streaming for this plan)
        if reqBody.Stream {
            s.proxyStream(c, resp, keyID, current.ID, start)
        } else {
            s.proxyBuffer(c, resp, keyID, current.ID, start)
        }
        return
    }

    // All upstreams exhausted -> 503 (D-06)
    c.JSON(503, errNoUpstream)
    s.logUsage(keyID, 0, false, 0, 0, time.Since(start))
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> /v1/* | Untrusted HTTP request with bearer token; must authenticate before forwarding |
| relay -> upstream | Outbound request carrying upstream API key; upstream response is semi-trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Spoofing | authMiddleware | mitigate | DB lookup WHERE token = ? AND enabled = true; reject with 401 on miss (D-01, D-02, D-03) |
| T-3-02 | Information Disclosure | authMiddleware | mitigate | Return identical 401 for "not found" and "disabled" -- no leakage of token existence (same error path for both) |
| T-3-03 | Denial of Service | handleRelay body read | mitigate | io.LimitReader capped at 10 MB; return 413 if exceeded |
| T-3-04 | Information Disclosure | relay error responses | mitigate | Never forward raw upstream error bodies to client; return ocp's own 503 JSON on all-fail |
| T-3-05 | Elevation of Privilege | relay outbound request | accept | Upstream BaseURLs are admin-configured (not user-supplied); no SSRF vector at this phase |
| T-3-06 | Denial of Service | logUsage goroutine | accept | Fire-and-forget goroutine may accumulate if DB is slow; acceptable at single-instance scale -- SQLite WAL writes are fast |
| T-3-07 | Information Disclosure | upstream API key in headers | mitigate | Replace Authorization header with upstream's key; do not copy client's original token to upstream; cloneHeaders strips hop-by-hop headers |
</threat_model>
